# Sample data (synthetic)

Generated by `scripts/make_samples.py`. Nothing here is a real measurement.

| File | Contents |
|---|---|
| `gnn_primer.pdf` | 3-page original primer on GNNs (message passing, GCN, GAT, sampling, limitations), written for this project (MIT). |
| `synthetic_gnn_experiments.csv` | GCN vs GAT, 3 seeds × 20 epochs, on the fictitious dataset `synthetic-citation-graph`. |
| `synthetic_graphsage_runs.json` | GraphSAGE, 2 seeds, nested `runs[].history[]` format. |

The curves come from seeded exponential-decay functions plus Gaussian noise. Do not cite them as benchmark
results.
